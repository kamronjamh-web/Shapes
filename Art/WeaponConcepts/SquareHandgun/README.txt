SQ / 01 - Square handgun review

A conventional handgun silhouette with a shallow, visible square-cartridge dock.
The frame is a continuous contoured mesh; the slide is tapered and chamfered.
Open trigger guard, shaped grip panels, cut slide grooves, and separate controls.

Open SquareHandgun.blend. The Review cameras show the silhouette and sockets.
GunRoot groups the complete model. ShapeSocket owns the removable SquareInsert.
The dock rim and side witness panel make the slotted square readable from above and in profile.
The fourth render lifts the insert to show the open pocket; the source file opens with it seated.
Later shapes can use the same socket with a different slide/upper silhouette.

RARITY PREVIEW
Select SquareInsert, open Object Properties > Custom Properties, and change rarity_tier.
0 Common (white), 1 Uncommon (green), 2 Rare (blue), 3 Legendary (purple),
4 Mythic (red), 5 Divine (gold). Values are read from EquipmentCatalogDefaults.cs.
Insert shell, slot rim, side witness, slide seams and grip heel share one driven material.
Material Preview or Rendered shading shows changes immediately; no add-on is needed.

MODULATOR PREVIEW
GunRoot custom properties: weapon_level (1-5), equipped_modulators (0-10).
Five recessed cartridges per side; ModulatorSocket01-10 are independent attachment anchors.
Slots alternate right/left from rear to front and follow the game's rarity/level unlocks.
Installed = keyed cartridge with type marker; empty = open contacts; locked = dark blanking cap.
Modulator markers retain their own catalog colors and are independent of shape rarity.
Default preview: Rare, level 5, three example modulators, six unlocked bays.
Examples show mounting/identification; the review file is not connected to player inventory.
Renders/06_full_modulator_capacity.png shows all ten installed with Divine rarity.
Renders/Rarities contains the six accent-color previews.
